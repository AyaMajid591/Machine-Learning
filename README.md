# Machine Learning Assignments

This repository contains my Machine Learning assignments completed during the semester using Python and Google Colab.

The assignments focus on data analysis, machine learning algorithms, model evaluation, and data preprocessing.

## Completed Tasks

### Task 1 — Project Setup and Dataset Analysis
Created a reproducible Python environment with fixed library versions. Selected the Pima Indians Diabetes Dataset, performed initial data analysis, and organized the project files.

### Task 2 — Gradient Descent
Implemented gradient descent for linear regression using NumPy. Compared the results with Scikit-learn and tested different learning rates to understand how they affect convergence.

### Task 3 — Custom Transformer and Pipeline
Created a custom transformer using BaseEstimator and TransformerMixin. Added it to a Scikit-learn Pipeline, tested it with new data, and evaluated its performance.

### Task 4 — Model Interpretation
Trained a Random Forest model and compared built-in feature importance with Permutation Importance. Used SHAP to explain individual predictions.

### Task 5 — Exploratory Data Analysis
Performed EDA on the Titanic dataset. Investigated missing values, outliers, and correlations. Tested three statistical hypotheses and checked for possible data leakage.

### Task 6 — Machine Learning Practice
Completed practical exercises using Python and Scikit-learn to understand machine learning concepts and model behavior.

### Task 7 — Machine Learning Practice
Applied machine learning and data analysis techniques, tested the results, and visualized findings using Python.
